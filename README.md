# Dungeon Fragments

![Unity](https://img.shields.io/badge/Made%20with-Unity-smoothgreen?style=flat-scale&logo=unity)
![Platform](https://img.shields.io/badge/Platform-Windows-blue)

**Dungeon Fragments** — это 2D top-down action RPG в жанре dungeon crawler, вдохновлённая игрой *Minecraft Dungeons*. 

Игроку предстоит исследовать процедурные уровни (или просто уровни), сражаться с ордами зомби и скелетов, собирать монеты, использовать зелья лечения и совершать рывки, чтобы выжить в опасных подземельях.

---

## ✨ Особенности игры

* **Динамичная боевая система:** Сражайтесь в ближнем бою с помощью меча или расстреливайте врагов издалека из лука.
* **Элементы выживания:** Следите за уровнем здоровья, вовремя используйте лечебные зелья и уклоняйтесь от сильных атак с помощью дэша.
* **Классический Pixel Art:** Приятная пиксельная графика в стиле лучших ретро-рогаликов.
* **Честная разработка:** Проект создан без использования генеративного ИИ (No generative AI used).

---

## ⌨️ Управление

* `LMB` (Левая кнопка мыши) — Перемещение / Атака мечом
* `RMB` (Правая кнопка мыши) — Стрельба из лука
* `Space` (Пробел) — Рывок (Дэш)
* `E` — Использовать зелье лечения
* `Escape` — Пауза

---

## 📦 Как запустить игру

1. Перейдите в раздел **[Releases](https://github.com/твой_ник/Dungeon-Fragments/releases)** на GitHub.
2. Скачайте последний доступный установщик `DungeonFragments_Setup.exe`.
3. Запустите файл и следуйте инструкциям установщика.
4. Запускайте игру ярлыком с рабочего стола и побеждайте монстров!
